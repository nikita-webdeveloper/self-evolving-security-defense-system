# Self-Evolving Security Defense System

An adaptive intrusion detection dashboard that analyzes log-based attack behavior
and learns recurring threat patterns over time.

## Features
- Threat classification (Normal / Suspicious / Attack)
- Real-time log visualization
- Attack memory learning
- Severity analytics dashboard

## Tech Stack
- Python
- Streamlit
- Pandas
- Matplotlib

## How to Run
1. Run `main.py`
2. Run `realtime_engine.py`
3. Start dashboard:
   streamlit run app.py
